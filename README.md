# 🎨 GMC RP ステッカー申請フォーム

**ゲーム内で使えるステッカーを、プレイヤーがブラウザから申請できる Web アプリ**

※ 現在は運用していません

</div>

GTA5 のロールプレイサーバー「GMC RP」の運営として、全プレイヤー向けに公開した Web アプリです。
プレイヤーはゲーム内で使うステッカーを簡単に申請でき、運営は申請されたステッカーを簡単に追加できます。

GMC RP は約 2 年間、日本トップの人気を誇ったサーバーです。
少人数の運営で回すために、このフォームのほかに「市民リスト」や「新商品申請フォーム」も作りました。

## 作った理由

以前は、Discord で申請された画像を運営が手作業でサーバーに追加していました。
これではあまりに効率が悪いので、運営は「サーバーに追加してよいか」を確認するだけで済むよう、作業を半自動化しました。

## 主な機能

| 画面 | 使う人 | 内容 |
| --- | --- | --- |
| 📝 **申請フォーム** | プレイヤー | PNG 画像をアップロードしてステッカーを申請 |
| 📋 **申請リスト** | プレイヤー | 追加済みのステッカーと、自分が申請したステッカーの状況を確認 |
| 🛠️ **管理画面** | 運営 | 申請をすべて確認し、ボタン 1 つで追加・キャンセル。追加済みの画像を ZIP でまとめてダウンロード |

## 工夫したところ

### アカウントなしで自分の申請を確認できる

プレイヤーにアカウントを作ってもらわなくても、自分のブラウザから申請したステッカーの一覧を見られるようにしました。
申請すると ID がブラウザ（`localStorage`）に保存され、申請リストではその ID を使って自分の申請を表示します。
初めて使った技術で、ほかの Web アプリを作るときにも応用できると考えています。

### 運営の手間を減らす管理画面

- 申請されたステッカーをすべて一覧で確認し、「追加」「キャンセル」のボタンを押すだけで処理できます
- 追加したステッカーは 50 個ずつのカテゴリに自動で分けられ、カテゴリごとに ZIP でダウンロードしてゲームサーバーに反映できます

この仕組みのおかげで、ステッカーの管理がとても楽になりました。

### サーバー容量を守る画像の制限

サーバーの容量が足りなくならないよう、1000×1000 より大きい画像は申請できないようにしました。
小さすぎず、ゲーム内に貼っても違和感のないサイズです。
形式は PNG だけに限定しています。

### いたずら申請への対策

悪意のある人から大量に申請されないよう、Google reCAPTCHA の認証を通らないと申請できないようにしました。
運用中、悪意のある大量申請は一度もありませんでした。

## 技術スタック

| | |
| --- | --- |
| **Frontend** | React 18, React Router, Tailwind CSS, Headless UI |
| **Backend** | Node.js, Express, MySQL, JWT, Multer, archiver（ZIP 作成） |
| **Security** | Google reCAPTCHA |
| **Infra** | Vercel（フロント）, Vercel Analytics |

```
プレイヤー ──▶ 申請フォーム（reCAPTCHA）──┐
                                          ├─▶ API サーバー（Express）──▶ MySQL
運営 ──▶ 管理画面（JWT でログイン）───────┘         │
                                                   └─▶ 画像を保存、ZIP にまとめて配布
```

このリポジトリにはフロントエンドのコードだけを入れています。API サーバーは GMC RP のほかのツールと共通です。

## ディレクトリ構成

```
frontend/src/
├── form/    # ステッカー申請フォーム
├── list/    # 申請リスト（追加済み＋自分の申請）
├── admin/   # 運営用のログインと管理画面
└── utils/   # ヘッダー、フッターなどの共通部品
```
